1. Executive Summary & Problem Statement

The rapid expansion of the digital economy has made web platforms critical national infrastructure, yet open web ecosystems remain intensely vulnerable. Over 43% of all global websites, powering SMEs, universities, healthcare portals, and public services, rely on open CMS architectures like WordPress. These systems face relentless attacks—averaging over 90,000 automated cyber-attacks every minute, ranging from SQL Injection (SQLi) and Remote Code Execution (RCE) to credential-stuffing botnets and Layer-7 DDoS extortion. Current enterprise security solutions (such as Cloudflare Enterprise or Imperva) cost thousands of dollars per month, lock users into opaque proprietary networks, and add significant latency to origin servers.

MDefender Pro eliminates this disparity by delivering a high-performance, cost-effective, and autonomous Web Application Firewall (WAF) ecosystem. Engineered with an asynchronous Python FastAPI cloud backend and a zero-dependency PHP client-side service container, MDefender Pro provides edge-level packet filtering, sub-millisecond AI attack classification, automated malware checksum auditing, and a real-time Core Web Vitals speed observatory at near-zero marginal cost.

2. Decoupled 3-Tier SaaS Control-and-Command Architecture

MDefender Pro employs a high-throughput decoupled architecture that completely isolates edge request processing from central telemetry storage, preventing database bottlenecks even under severe attack floods:

Tier 1: Client Edge Agent

  • Zero-Dependency PHP Container: Executes before WordPress core hooks to block attacks with zero bootstrap latency.
  • Circuit Breaker Isolation: Sandboxes all 17 engines with try...catch(\Throwable) to guarantee 100% site availability.
  • Zero API Blocking: Evaluates WAF rules locally without waiting for external cloud HTTP calls.

Tier 2: Cloud Control Plane

  • FastAPI Async Python Server: Powers centralized fleet management, token auth & event streaming.
  • Zero-Bloat MongoDB: Stores only fleet metadata and configuration (all logs stay distributed on client nodes).
  • Synthetic Uptime & SSL: Automated Let's Encrypt certificates and edge health probing.

Tier 3: Telemetry Observatory

  • Modern React 18 (Vite): Real-time management console and attack audit dashboard.
  • Fleet Speed Observatory: Real-time Core Web Vitals (Mobile 4G vs. Desktop).
  • 1-Click Security Hardening: Instant activation of login hide, 2FA, & header policies.

4. Integrated Security Modules & Enterprise Features
1. Next-Gen Web Application Firewall (WAF)
Deep inspection of GET, POST, URI, and HTTP headers against SQLi, XSS, Remote Code Execution (RCE), and Path Traversal with custom regex and AI heuristics.
2. Proof-of-Work (PoW) Anti-DDoS Challenge
Under-attack protection running cryptographic in-browser SHA-256 compute challenges. Nullifies 100% of Layer-7 bot floods without frustrating visual CAPTCHAs.
3. Stealth Admin Gateway & CIDR Whitelist
Obfuscates default /wp-login.php with cryptographic secret tokens and restricts admin dashboard access strictly to authorized IP subnets via 403 barriers.
4. Native RFC-6238 2FA & Security Hardening
Enforces authenticator app TOTP (Google/Microsoft Authenticator), file upload code-execution bans, directory lockdown, and security headers (HSTS, CSP).
5. Core Web Vitals Speed Observatory
Dual simulated Mobile (4G) and Desktop speed auditor reporting authentic LCP, FCP, CLS, TTFB, and actionable asset optimization recommendations with zero fake values.
6. Cloud Malware Scanner & Quarantine
High-speed signature and AST-heuristic scanner comparing client filesystem against 5.24M official WordPress checksums to detect and isolate zero-day web-shells.
